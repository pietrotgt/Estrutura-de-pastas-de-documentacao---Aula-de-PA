# Estrutura-de-pastas-de-documentacao---Aula-de-PA

## index.html - Calculadora Simples

### Descrição
Uma página HTML interativa que realiza operações matemáticas básicas entre dois valores numéricos.

### Funcionalidades
- **Soma**: Calcula a adição entre dois números
- **Subtração**: Calcula a diferença entre dois números
- **Multiplicação**: Calcula o produto entre dois números
- **Divisão**: Calcula o quociente entre dois números

### Como usar
1. Insira o primeiro valor no primeiro campo de entrada
2. Insira o segundo valor no segundo campo de entrada
3. Clique no botão "CALCULAR"
4. O resultado das quatro operações será exibido em um alerta

### Estrutura do código

#### Elementos HTML
- Dois campos de entrada (`input type="number"`)
- Um botão de ação (`input type="button"`)

#### Função JavaScript
- `calcular()`: Função principal que:
  - Obtém os valores dos campos de entrada
  - Converte os valores para números
  - Realiza as quatro operações básicas
  - Exibe os resultados em um alerta
