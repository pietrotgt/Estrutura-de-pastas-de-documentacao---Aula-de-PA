# Funcionalidades

## Objetivo

Descrever as principais funcionalidades disponíveis na aplicação.

## Operações Matemáticas

A calculadora permite realizar as seguintes operações:

- **Soma:** realiza a adição de dois números.
- **Subtração:** calcula a diferença entre dois números.
- **Multiplicação:** calcula o produto de dois números.
- **Divisão:** divide um número por outro, desde que o divisor seja diferente de zero.

## Funcionamento

1. O usuário informa os valores necessários.
2. Seleciona ou executa a operação desejada.
3. A aplicação realiza o cálculo.
4. O resultado é apresentado na tela.

## Regras de Utilização

- Os valores informados devem ser válidos para a operação.
- Na divisão, não é permitido utilizar zero como divisor.
- Os resultados dependem dos valores fornecidos pelo usuário.

## Resultado Esperado

A aplicação deve realizar as operações matemáticas implementadas e apresentar os resultados corretamente.

## Observação

As funcionalidades descritas devem corresponder ao comportamento real da calculadora implementada no projeto.
